🔧 Outils de réparation ponctuelle

Ces outils agissent sur le compte ciblé par e-mail ci-dessous — pas sur ton propre compte administrateur. Retirés de l'app principale le 20/08/2026 : ce ne sont pas des réglages d'usage courant, réservés depuis à cet écran.

Recalculer le badge km cumulés

Reconstruit le total à partir des séances réellement validées, tous plans confondus pour ce compte.

Plan ciblé (pour les 2 outils ci-dessous)

Si ce compte a plusieurs plans, choisis lequel cibler — sinon le plan le plus récemment créé est utilisé par défaut, qui n'est pas toujours celui réellement suivi.

Vérifier la cohérence des phases

Détecte et corrige une éventuelle divergence entre l'étiquette de phase stockée sur chaque semaine et la vraie structure du plan ciblé.

Corriger le sous-type d'une séance qualité

Force le sous-type d'une séance qualité précise (semaine + jour), sur le plan ciblé. Le jour est indexé 0 (lundi) à 6 (dimanche).

Export global

Découvre automatiquement toutes les tables de la base (via introspection PostgREST) et exporte l'intégralité de leur contenu en un fichier JSON téléchargeable. Filet de sécurité en cas de désastre complet — le plan Supabase actuel (Free) ne fait aucune sauvegarde automatique.

Export ciblé par utilisateur

Exporte uniquement les données d'un testeur précis (retrouvé par e-mail), y compris ses décisions du moteur. Le scénario le plus probable en pratique : un testeur signale un souci sur son plan.

Réinjection

Réimporte un fichier JSON exporté précédemment (global ou ciblé). Écrase les lignes existantes ayant le même identifiant (upsert). Si l'export cible un utilisateur dont le compte a depuis été supprimé, le compte est recréé automatiquement avec le même identifiant avant réinjection des données.

Diagnostic des cascades ON DELETE

Vérifie que chaque table applicative liée à un utilisateur (colonne user_id/id_utilisateur) supprime bien ses lignes automatiquement quand le compte Auth est supprimé (ON DELETE CASCADE) — sinon api/delete-account.js échoue en erreur de contrainte. À lancer occasionnellement (ex. avant une mise en production), pas à chaque table ajoutée.
